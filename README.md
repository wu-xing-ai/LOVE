## 这是什么

不是一个爱心动画。

是一个 **拥有引力场的宇宙生命体**：

- **中央** —— 一团由真实流体模拟驱动的绯红等离子体，被精确约束成心的形状
- **边缘** —— 白色能量骨架勾勒出带 V 形凹口的经典轮廓，随呼吸流动、永不失形
- **外围** —— 上万颗星辰沿倾斜椭圆轨道环绕公转：进动、交叉、被心跳推涌
- **深空** —— 玫瑰色云霭与冷蓝雾霭之间，粒子银河缓缓旋转

你无法一眼判断它是粒子、流体，还是生命。这正是目的。

## 特性

### 🌊 真·流体心脏

底层是一台跑在 WebGL2 图集式 3D 纹理上的 **Navier-Stokes 求解器**：

```text
半拉格朗日自平流 → 外力注入 → 涡度约束 → 压力泊松(18×Jacobi) → 梯度相减
```

44³ 体场每帧完整求解一次。心形不约束粒子 —— 它向**流体本身**注入表面环流、软膜压与心跳脉冲；17.6 万示踪粒子被介质携带对流。形状不是画出来的，是从湍流中涌现的，像铁磁流体遇到磁场。

### 💓 有心跳的能量波

六相包络循环驱动一切：

```text
静息 → 收缩 → 蓄能(吸积盘拧紧) → 爆发(径向脉冲+行波) → 弥散 → 回聚(欠阻尼弹性)
```

每一次心跳，一圈能量波从核心推出，扫过流体、扫过星河 —— 外围轨道粒子被瞬间推动，然后被引力重新捕获。

### 🕸 三维轮廓骨架

15,000 高亮粒子经**牛顿迭代投影**严格贴合 Taubin 隐式曲面，构成三族线框：

- **主轮廓脊** —— 正面剪影真解，保证上半部 V 形凹口清晰可辨
- **纬线环 ×5** —— 不同高度的水平截面环，一眼读出体积
- **经线脊 ×6** —— 纵贯前后包络，强化心尖与纵向结构

背面减淡分级让线框拥有真实的体积纵深。

### 🪐 开普勒粒子星系

上万颗外围星辰按 **ω ∝ a^(-3/2)** 差速公转：

| 层级 | 行为 |
| ---- | ---- |
| 近轨 | 稀疏、快速、明亮，受心能强耦合 |
| 中轨 | 四条倾斜行星环带 + 全随机倾角轨道，节点/拱点双向进动 |
| 远轨 | 大椭圆（e ≤ 0.55），均匀球面分布，360° 包裹心体 |

心跳越强，星河流速越快；鼠标划过，轨道弯曲偏移；点击释放冲击波，星辰暂离轨道，再被引力一一收回。

### ✨ 渲染管线

HDR 加法累积轨迹残影 → ¼ 分辨率高斯辉光链 → ACES 色调映射 → 冲击波屏幕空间折射 → 色差 → 晕影 → 胶片颗粒

多普勒亮度偏移 · 伪景深 CoC · 涡度致紫辉 · GPU 电弧丝线 · 速度拉伸光轨

## 运行

无构建、无依赖、无网络请求。

```bash
# 直接双击 index.html 即可
# 或本地起服务：
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

要求支持 **WebGL2** 的浏览器（Chrome / Edge / Firefox / Safari 16+）。

## 性能自适应

内置四级降载：帧率低于阈值时自动缩减分辨率与粒子数（网格 420² → 230²），后台标签页自动暂停，上下文丢失自动恢复。从独显到核显都能流畅运行。
